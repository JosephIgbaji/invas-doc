## System Global Roles

* **Super Admin:** Full platform ownership, billing, user provisioning, and API keys.
* **Manager:** Access to all reports, queues, CRM deals, and campaign creation.
* **Agent:** Restricted to assigned conversations, contacts, and personal performance stats.
* **Catalog Editor:** Scoped strictly to inventory and product catalog management.

---

## Custom Roles & Permissions

Create granular roles tailored to specific company duties with explicit toggles for:
* Template creation and submission
* Campaign broadcasting rights
* Contact export permissions
* Call recording playback rights
