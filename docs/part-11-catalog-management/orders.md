# Order Management (Premium)

When customers add products to their WhatsApp cart and place an order, inVAS captures the complete transaction details.

---

## Order Status Lifecycle

```
[ New Order ] ──> [ Confirmed ] ──> [ Delivering ] ──> [ Completed (Terminal) ]
                                             └──> [ Returned / Canceled ]
```

* **Viewing Order Details:** View customer line items, quantities, shipping addresses, and payment receipts.
* **Exporting Orders:** Export order datasets to CSV/Excel for fulfillment and ERP synchronization.
