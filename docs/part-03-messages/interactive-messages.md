# Interactive Message Types

Interactive messages provide users with clickable elements that make conversations faster, eliminate typing errors, and increase conversion rates.

## 1. Quick Reply Buttons (Button Message)
* Presents up to **3 clickable buttons** below text or media.
* When the user taps a button, its title is sent back as a normal message, allowing bots and agents to immediately trigger the next response branch.

## 2. CTA URL Button (Link Message)
* Contains a single prominent button with an external hyperlink (e.g., *"Visit Website"*, *"Pay Invoice"*).
* Clicking the button opens the destination URL directly in the customer's web browser.

## 3. List Messages
* Presents a structured menu button (e.g., *"Select Option"*).
* Tapping the button opens a clean popup menu supporting:
  * Up to **10 selectable options** grouped into sections.
  * Each item includes a bold **Title** (up to 24 chars) and an optional **Description** (up to 72 chars).
* Ideal for product menus, service selection, FAQ topics, and department selection.

## 4. Location Request Messages
* Sends a specialized system prompt asking the customer to share their current GPS location.
* Customers can tap **Send Location** in WhatsApp with a single tap, ideal for delivery dispatch and store locators.

## 5. WhatsApp Flows
* Embeds native, multi-screen micro-apps directly within WhatsApp chats.
* Customers can fill out forms, pick appointment dates, configure insurance quotes, and submit feedback without ever leaving the conversation.

## 6. Multi-Product List
* Showcases up to **30 items** from your connected Meta Commerce Catalog.
* Users can view product images, descriptions, prices, and add items to an in-chat cart.

## 7. Call Permission Request
* Sends an official compliance prompt asking the user for authorization to initiate a business voice call.
