# Non-Interactive Message Types

Non-interactive messages deliver multimedia and content directly to the user's chat thread.

---

## Supported Media Types

| Type | Formats Supported | Max File Size | Best Practices |
| :--- | :--- | :--- | :--- |
| **Text** | UTF-8 Plain text, emojis, markdown (`*bold*`, `_italics_`, `~strike~`, code) | 4,096 characters | Keep body copy concise and scannable. |
| **Image** | JPEG, PNG | 5 MB | Minimum 800x800px; square or 16:9 aspect ratio. |
| **Video** | MP4 (H.264 + AAC audio) | 16 MB | 720p resolution; keep under 60 seconds for fast delivery. |
| **Voice / Audio** | AAC, MP3, OGG, AMR | 16 MB | Use voice notes for humanized representative updates. |
| **Document** | PDF, DOCX, XLSX, PPTX | 100 MB | Perfect for invoices, contracts, brochures, and receipts. |
| **Location** | GPS Latitude & Longitude coordinates | N/A | Displays an interactive map pin with business name and address. |
