## Core Components of Bot Factory

The builder is composed of three primary areas:
1. **The Canvas (Center):** Infinite workspace where bot cards are placed, moved, and interconnected via directional connectors.
2. **Card Selector (Sidebar):** Library of building blocks organized into **Message Cards**, **Action Cards**, **Saved Messages**, and **Components**.
3. **Card Configuration Drawer:** Contextual inspector where parameters, text, media, buttons, and variables are customized.
