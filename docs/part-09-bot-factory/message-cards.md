# Bot Factory: Message Cards

Message cards deliver content to the user during the automated bot session.

---

## Available Message Cards

1. **Text Card:** Sends plain or markdown-formatted copy.
2. **Button Message (Quick Replies):** Combines a header, body, footer, and up to 3 branch buttons.

<div class="doc-image">
  <img src="/images/pdf/page_73_img_1.png" alt="Button Message Node" />

</div>

3. **Link Message (CTA Button):** Displays a message with a direct external URL button.
4. **Image / Video / Audio Cards:** Transmits multimedia files to capture attention or explain features.

<div class="doc-image">
  <img src="/images/pdf/page_75_img_1.png" alt="Image Message Flow" />
  <div class="caption">Figure 9.5: Image Message card used in a visual sales flow</div>
</div>

5. **WhatsApp Flow Card:** Invokes a native interactive form.
6. **Template Card:** Triggers an approved template message directly from the bot.
